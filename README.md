# Agents

A collection of AI agents, skills, and workflows.

## Structure

```
agents/
├── skills/          # Reusable skills (.md)
├── workflows/       # Multi-agent workflow scripts (.js)
├── prompts/         # System prompts and prompt templates
└── tools/           # Custom MCP tools and integrations
```

## Usage

Each agent/skill includes its own README with setup and usage instructions.
